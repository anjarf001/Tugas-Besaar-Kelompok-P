# Tugas-Besaar-Kelompok-P
Aplikasi penyedia jasa titipan (Jastip.in) memiliki beberapa penyedia yang menawarkan berbagai jenis barang. Satu barang dapat ditawarkan oleh beberapa penyedia dengan harga dan ketersediaan yang berbeda. Pelanggan dapat melakukan transaksi pembelian dari penyedia yang dipilih. Seluruh transaksi dicatat untuk memudahkan pencarian riwayat pembelian.
